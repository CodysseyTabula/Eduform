# IEP Planning Support Service

## 📋 개요

### IEP란?

**IEP**(Individualized Education Program, 개별화 교육 계획)는 특수교육 대상 학생을 위한 맞춤형 교육 계획서입니다. 각 학생의 개별적인 학습 능력, 발달 수준, 특성을 고려하여 연간 및 학기별 교육 목표를 설정하고, 주차별 학습 내용과 필요한 학습 자료를 체계적으로 계획합니다.

### 이 시스템의 목적

기존에는 IEP 작성이 수동으로 이루어져 시간이 많이 소요되고, 학생별 특성을 반영한 맞춤형 계획 수립이 어려웠습니다. 본 시스템은 **AI 기반 자동 생성 기능**을 통해 다음과 같은 문제를 해결합니다:

- **시간 절약**: 수동 작성 대신 학생 프로필 정보만 입력하면 자동으로 IEP가 생성됩니다
- **맞춤형 계획**: 학생의 인지 수준, 교과 수행 수준, K-WISC-V 검사 결과 등 20개 항목의 프로필 정보를 종합 분석하여 개인화된 교육 계획을 생성합니다
- **체계적 관리**: 학기별 IEP 버전 관리, 파일 저장, Word 문서 다운로드 등 전체 생명주기를 지원합니다

### 시스템 작동 방식

1. **학생 정보 입력**: 학생의 기본 정보(이름, 학년, 학기)와 상세 프로필(인지 수준, 교과 수행 수준, K-WISC-V 검사 결과, 선택한 학습 도메인 등)을 입력합니다
2. **IEP 버전 생성**: 학기별로 IEP 버전을 생성하여 관리합니다
3. **AI 자동 생성**: 입력된 학생 프로필을 기반으로 AI 모듈이 다음 3가지 파일을 자동 생성합니다:
   - **연간/학기 목표** (`goals.json`): 선택한 도메인별로 연간 목표와 학기 목표를 생성
   - **주차별 학습 계획** (`weekly_plan.json`): 20주간의 주차별 학습 내용을 생성
   - **주차별 학습 자료** (`weekly_materials.json`): 각 주차에 필요한 학습 자료 URL을 제공
4. **문서 다운로드**: 생성된 IEP를 Word 문서(DOCX) 형식으로 다운로드하여 활용할 수 있습니다
5. **웹 인터페이스**: 학생 목록, IEP 목록, 강의 계획서를 웹 브라우저에서 쉽게 조회하고 관리할 수 있습니다

## 🛠️ 기술 스택

- **Backend**: FastAPI, PostgreSQL, SQLAlchemy, Python
- **Frontend**: React, TypeScript, Vite
- **Infrastructure**: Docker, Docker Compose

## 📚 주요 기능

### 1. 학생 관리

학생의 기본 정보를 등록하고 조회할 수 있습니다. 각 학생은 고유 ID를 가지며, 여러 학기에 걸쳐 IEP를 생성할 수 있습니다.

**기능:**
- 학생 등록: 이름, 생년월일 등 기본 정보 입력
- 학생 목록 조회: 등록된 모든 학생 목록 확인
- 학생별 IEP 이력 조회: 특정 학생의 모든 IEP 버전 확인

### 2. IEP 버전 관리

학기별로 IEP 버전을 생성하고 관리합니다. 한 학생은 여러 학기에 걸쳐 여러 개의 IEP 버전을 가질 수 있으며, 각 버전은 독립적으로 관리됩니다.

**기능:**
- IEP 버전 생성: 학기 정보(시작일, 종료일)와 함께 새 IEP 버전 생성
- 버전별 IEP 파일 관리: 각 버전에 속한 목표, 계획, 자료 파일들을 개별적으로 관리
- 최신 IEP 조회: 특정 학생의 가장 최근 IEP 버전 확인

### 3. AI 기반 IEP 파일 자동 생성

학생 프로필 정보를 기반으로 AI가 자동으로 3가지 유형의 IEP 파일을 생성합니다. 학생 프로필은 다음 20개 항목을 포함합니다:

**학생 프로필 정보:**
- 기본 정보: 이름, 생년월일, 학년, 현재 학기, 학기 기간
- 발달 수준: 보호자 의견, 인지 수준, 사회심리 수준, 운동 일상생활 수준
- K-WISC-V 검사 결과: 언어이해지표(VCI), 시공간지표(VSI), 유동추론지표(FRI), 작업기억지표(WMI), 처리속도지표(PSI), 전체 IQ(FSIQ)
- 교과 수행 수준: 국어 수행 수준, 수학 수행 수준
- 학습 도메인: 국어 도메인 선택(듣기말하기, 읽기, 쓰기, 문법, 문학, 매체), 수학 도메인 선택(수와 연산, 변화와 관계, 도형과 측정, 자료와 가능성)

**생성되는 파일:**

1. **연간/학기 목표** (`goals.json`)
   - 선택한 각 도메인별로 연간 목표와 학기 목표를 생성
   - 예: 국어 "읽기" 도메인 → 연간 목표와 학기 목표 자동 생성
   - 학생의 수행 수준과 검사 결과를 반영하여 적절한 난이도로 설정

2. **주차별 학습 계획** (`weekly_plan.json`)
   - 20주간의 주차별 학습 내용을 생성
   - 각 주차마다 학습 주제, 학습 내용, 활동 방법 등을 포함
   - 생성된 목표를 바탕으로 단계적이고 체계적인 학습 계획 수립

3. **주차별 학습 자료** (`weekly_materials.json`)
   - 각 주차에 필요한 학습 자료의 URL 또는 참고 자료 정보를 제공
   - 실제 수업에서 활용할 수 있는 구체적인 자료 안내

### 4. DOCX 문서 다운로드

생성된 IEP 파일들을 통합하여 Word 문서(DOCX) 형식으로 다운로드할 수 있습니다. 문서에는 다음 내용이 포함됩니다:

- IEP 메타데이터: 학생 정보, 학기 정보, 생성 일시
- 연간/학기 목표: 도메인별 목표 목록
- 주차별 학습 계획: 20주간의 상세 학습 계획
- 주차별 학습 자료: 각 주차별 참고 자료 정보

### 5. 웹 인터페이스

React 기반의 직관적인 웹 인터페이스를 제공합니다. 별도의 API 호출 없이 브라우저에서 모든 기능을 사용할 수 있습니다.

**주요 페이지:**
- **학생 목록 페이지**: 등록된 모든 학생을 조회하고, 새 학생을 등록할 수 있습니다
- **IEP 목록 페이지**: 특정 학생의 모든 IEP 버전을 조회하고, 새 IEP 버전을 생성할 수 있습니다
- **강의 계획서 페이지**: 특정 IEP 버전의 상세 내용(목표, 주차별 계획, 학습 자료)을 조회하고, DOCX 파일을 다운로드할 수 있습니다
